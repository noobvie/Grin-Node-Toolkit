Names

The blocked-word list for every name a player types

Blocked words

Game nicknames on /play/ and donor names on the donate page are checked against this list and go live at once, with no review queue. A built-in list of common slurs and profanity, and the reserved words, always apply on top, so leave this empty unless you need more. Reserved for nicknames: operator, admin, moderator, support, staff, official, mod, bot, pool, this pool's name, names starting with "guest". Reserved for donor names: admin, official, operator, support, staff, pool, grinium, prize, jackpot, winner, this pool's name. A donor name may contain spaces, and a short entry also matches one word of it (moon refuses Moon Boys).

How an entry matches. Case, spaces, - _ . & ' and look-alike digits (0 1 3 4 5 7 for o i e a s t) are ignored, so sc4m and Scam are the same entry. An entry of 4 letters or fewer matches only a name that is that word (with digits at either end ignored): ass refuses Ass and A55 but not Classic. An entry of 5 letters or more matches anywhere in a name. Start a line with * to make a short entry match anywhere (*crap also refuses Scrapbook), or with = to make a long one match only the whole name (=scammer refuses Scammer, not Scammers).

A player or donor whose name hits the list is told only that the name isn't allowed — never which word. The list does not remove names that are already live: Games → Nicknames and Donors → Donor names mark every live name the list would now refuse, so you can remove it there. Up to 500 entries of up to 32 letters or digits each. Donor names use a change at once; the games service picks it up within a minute and keeps the last list it received if the pool is unreachable.
