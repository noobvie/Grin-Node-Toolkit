Abandoned Balances

When on, an address with no accepted share, no successful payout and no withdrawal request for the dormancy window, still holding a balance, is swept into the community prize pool (given away through the pool's published draws). This is final and it is never operator revenue. The owner can reclaim any time before disposition simply by requesting a payout, which resets their countdown (even if that payout later fails) — the account page shows a per-address countdown, and the payments page lists dormant balances publicly (masked). Sweeps only run while the incentive draws (Incentives tab) are enabled, so a balance is never moved into a pool that can't pay back out. You must disclose this in your Terms of Service before enabling. The clock is grandfathered: the first run after you enable stamps the start date and disposes nobody, so every address gets a full window of runway.

Months of total inactivity (no share, no payout) before a balance becomes eligible. Minimum 12 — a long, unmistakable abandonment window before a final disposition.
Recent-activity boundary: an address seen within this many days is treated as still active and is never listed as dormant or swept. (It no longer selects recipients — swept balances go to the prize pool, not a per-miner split.)

Goblin / Nostr Payouts (experimental)

Lets a miner register a Goblin username and be paid over Nostr (no Tor listener needed). This rail pays a username, not the mining address's own wallet, so it is guarded by a registration + cooldown + key-pin on top of the ownership gate. Requires npm install in the backend (adds nostr-tools + ws) and a backend restart. Test on testnet / with tiny amounts first.

A newly registered Goblin destination can't receive a payout until it is this old. Gives the real owner time to spot and undo a hijack. 0 disables the wait (not recommended).
How long a delivered-but-unanswered Goblin payout stays locked before it auto-refunds. Goblin AutoReceives, so a live miner's wallet answers in seconds. Short is safe — expiry cancels the tx and returns the balance; a late reply is ignored (never a double-pay). Min 2 (the sweep runs every 60s).
One hostname per line. The ONLY domains a username is resolved against — the SSRF / look-alike-domain guard. Leave as goblin.st unless you know why.
