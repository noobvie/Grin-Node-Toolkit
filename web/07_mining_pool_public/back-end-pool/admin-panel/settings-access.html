Session & Security

          

            
            
            

              Sign an admin out after this long with no activity. Activity means
              real interaction with the panel — moving the pointer, typing, tapping. It is
              deliberately not measured from network requests: several pages refresh
              themselves on a timer, so a tab left open on the dashboard would keep a
              request-based session alive forever. While you are working, the session renews
              silently and you are not interrupted.
              
Maximum 24 hours: this is also how long a signed-in browser stays valid
              after you use Revoke sessions or change the password, so a long window
              means a stolen laptop keeps admin access for that long.
            

          


          

            
            
            

              Hard limit counted from when you logged in, regardless of activity — a session
              that renews all day still ends here and needs the password again. Set below the
              idle timeout and the idle timeout wins (the two would otherwise contradict).
            

          


          

            
            
          

        


        

          
Public Network Map Data

          

            Controls the two feeds behind /network-map.html
            (/api/pool/topology and /api/network/peers).
            Neither ever returns an IP address, and no coordinate is ever resolved: a miner or
            gateway is located to its country only, drawn as the filled country
            itself, with the marker on that country's exact centroid — so the shape states
            exactly the precision we hold. Together they still publish which countries
            mine here and which countries this node peers with. Off by default. While
            off, both endpoints return 404 and the page renders its illustrative sample globe.
          

          

            
            
          

          

            
            
            

              Applies only when publishing is on. A country with fewer than this many miners
              or peers is folded into an unnamed Other bucket instead of being named,
              so a country holding one participant never points at one person. Totals still
              include them. Raise it on a small pool; 1 disables the protection.
            

          

          

            
            
            
            

              Where this central pool server is, as a 2-letter ISO code (VN,
              DE, US). The box cannot detect this itself — it sits
              behind nginx and usually a CDN. Blank derives it from the region location set in
              Script 07 → 2) Configure, then this box's own card in
              Regions, then the busiest gateway. If every source is
              blank the globe draws no hub marker rather than guessing a spot —
              and the same applies to a code the map holds no position for (it carries centroids
              for the ~54 countries Grin mining and nodes actually appear in). Use
              GB, not UK.
            

          

        


        

          
Banned Miner Passwords (ownership gate)

          

            Stratum passwords listed here are never accepted as ownership proof on the
            public account page — additions on top of the built-in list (x, 123,
            worker, per-vendor factory defaults, anything under 8 characters, and any single
            repeated character such as xxxx or 0000). Add entries when you
            spot a new firmware default in the wild. Case-insensitive; the built-in list cannot be removed.
          

          

            
            
            
Takes effect within a minute of saving — an added password immediately stops
            counting as proof, even for accounts that already recorded it.
