Games · Nicknames

Players on /play/ choose a nickname of 3–20 letters and digits. It is checked automatically and goes live at once — there is no queue. The check refuses reserved words (operator, admin, moderator, support, staff, official, mod, bot, pool, this pool's name, names starting with "guest"), the built-in slur list, your blocked words, the chat word list, banned names below, and any name that reads the same as another player's (case, look-alike digits ignored). A nickname is always shown together with the masked address — NightShift (grin1abcd…wxyz) — so copying one does not make you someone. Moderators can remove a name from /play/; banning a name and blocking a player are yours. Every action here asks for your admin password again. Switch nicknames off under Overview & settings.

What each action does

  • Remove — the name stops showing at once; the player sees your reason on /play/ and can choose another (once their change cooldown is over).
  • Ban name — removes it from whoever holds it AND refuses it, in every spelling that reads the same (Sp4rky = sparky), to everyone from now on. Players are only told the name "isn't available".
  • Block player — removes their name and stops that address from setting any nickname until you unblock it. Chat and games are not affected.
  • Now refused by… — a live name the rule would refuse today (you added a word after it went live). Nothing happens to it by itself: remove it if you agree.
