Ads

Promotions shown on the public site — a self-hosted banner image, a native text card (headline + button, no design needed), or an ad-network code snippet — each bound to a placement. When a placement has several active ads they rotate automatically, one at a time (interval configurable below).

All ads

Multiple active ads in the same placement rotate on the public site — one at a time, advancing every 8 s. Weight sets the cycle order (highest first); a single ad just shows permanently. Views/clicks are coarse counters (no visitor data stored).

s

Sidebar layout. In rail mode the sidebar placement is a slim vertical strip fixed in the empty page margin (screens ≥ 1366 px only) — it costs the page layout nothing, peeks out for a while, tucks itself away against the edge, then slides back with the next creative. Visitors can pull it out by its tab or dismiss it for the visit. Use tall creatives here (160×600). On phones and narrow screens portrait creatives are dropped entirely — an in-flow ad there spans the full column, so a tall banner would be a screenful of scrolling. Only landscape or square creatives are served below 1366 px, so keep your mobile inventory in the header, in-content and footer placements.
