Goblin / Nostr Payouts (experimental)

Lets a miner register a Goblin username and be paid over Nostr (no Tor listener needed). This rail pays a username, not the mining address's own wallet, so it is guarded by a registration + cooldown + key-pin on top of the ownership gate. Requires npm install in the backend (adds nostr-tools + ws) and a backend restart. Test on testnet / with tiny amounts first.

A newly registered Goblin destination can't receive a payout until it is this old. Gives the real owner time to spot and undo a hijack. 0 disables the wait (not recommended).
How long a delivered-but-unanswered Goblin payout stays locked before it auto-refunds. Goblin AutoReceives, so a live miner's wallet answers in seconds. Short is safe — expiry cancels the tx and returns the balance; a late reply is ignored (never a double-pay). Min 2 (the sweep runs every 60s).
