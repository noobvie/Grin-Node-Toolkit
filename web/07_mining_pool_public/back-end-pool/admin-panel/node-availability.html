Node Availability

Two observers of the same node, shown side by side and never merged. The pool view is this pool's own probe every 30 s: could it get a status from its node? It also catches a wrong API secret or a pool-side fault, and it knows nothing about planned stops. The node box view comes from the node event recorder on the node's host. It knows the process, its log and every toolkit stop, so a planned stop there is listed but not counted. When the two disagree, that is the finding. All times UTC.
