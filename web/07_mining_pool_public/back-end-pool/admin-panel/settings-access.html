Public Network Map Data

          

            Controls the two feeds behind /network-map.html
            (/api/pool/topology and /api/network/peers).
            Neither ever returns an IP address — Grin peer IPs never leave the database and
            every point on the globe is randomised inside its country — but together they
            publish which countries mine here and which countries this node peers
            with. Off by default. While off, both endpoints return 404 and the page
            renders its illustrative sample globe.
          

          

            
            
          

          

            
            
            

              Applies only when publishing is on. A country with fewer than this many miners
              or peers is folded into an unnamed Other bucket instead of being named,
              so a country holding one participant never points at one person. Totals still
              include them. Raise it on a small pool; 1 disables the protection.
            

          

        


        

          
Banned Miner Passwords (ownership gate)

          

            Stratum passwords listed here are never accepted as ownership proof on the
            public account page — additions on top of the built-in list (x, 123,
            worker, per-vendor factory defaults, anything under 8 characters, and any single
            repeated character such as xxxx or 0000). Add entries when you
            spot a new firmware default in the wild. Case-insensitive; the built-in list cannot be removed.
          

          

            
            
            
Takes effect within a minute of saving — an added password immediately stops
            counting as proof, even for accounts that already recorded it.
