Games · Nicknames

Players on /play/ can ask for a nickname. Nothing a player types is shown to anyone else until you approve it here, and an approved nickname is always shown together with the masked address — Night Shift (grin1abcd…wxyz) — never on its own, so copying someone's nickname does not make you them. Names that contain "operator", "admin" or "moderator", look like an address, or match another player's live nickname are refused before they reach this queue. Every action here asks for your admin password again. Switch nicknames off under Overview & settings.

Nicknames are switched off: players cannot ask for one, and every page shows masked addresses only. Approved names are kept and come back when you switch it on.

What the flags mean

  • Reserved word — pool, grinium, official, support, staff, prize, jackpot, winner, mod or bot: it could read as speaking for the pool.
  • Word list — it contains an entry of the chat word list (Chat & moderation).
  • Same as a live name — another player already has a nickname that reads the same (case, spaces, - _ and look-alike digits ignored). It cannot be approved.
  • Same as a waiting name — another request reads the same. Only the first one you approve can go live.

Flags are hints, never decisions. A rejection reason is shown to the player on /play/.
